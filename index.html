Ollama 功能与应用报告

摘要：Ollama 是一个强大的本地大模型运行平台，除了运行 DeepSeek 之外，还能做许多有趣且实用的事情。本报告基于常见使用场景，系统介绍 Ollama 的多种功能及其实现方法，帮助用户全面了解并利用这一工具。

1. 运行各种开源大模型

Ollama 支持成百上千种开源模型，只需一条命令即可下载并运行。以下是一些常用模型：

模型 命令 特点
Llama 3 ollama run llama3 Meta 出品，通用能力强
Qwen 2.5 ollama run qwen2.5 阿里出品，中文友好
Mistral ollama run mistral 欧洲团队，轻量高效
Gemma 2 ollama run gemma2 Google 出品，适合多种任务
Phi 3 ollama run phi3 微软出品，小模型但聪明
CodeLlama ollama run codellama 专门写代码的模型
Llava ollama run llava 可以看图片的多模态模型
Nomic Embed ollama pull nomic-embed-text 文本嵌入模型，用于搜索/分类

完整模型列表可在 Ollama 模型库 中查看。

2. 把 Ollama 变成 API 服务

Ollama 安装后会自动在后台启动一个服务，默认地址为 http://localhost:11434。这意味着其他程序可以通过网络请求调用本地大模型，就像调用 ChatGPT 的 API 一样。

用途举例

  • 在 Python 脚本中调用本地模型
  • 让手机或其他电脑访问你电脑上的模型
  • 接入自动化流程（自动回复邮件、生成摘要等）

简单测试

curl http://localhost:11434/api/generate -d '{
  "model": "deepseek-r1:7b",
  "prompt": "你好，你是谁？",
  "stream": false
}'

会收到一段 JSON 回复，包含模型回答。

兼容 OpenAI API

Ollama 兼容 OpenAI 格式，可以在代码中将 base_url 指向 http://localhost:11434/v1。

3. 搭建图形聊天界面

默认终端界面不够友好。可以安装 Open WebUI 或 Chatbox 获得类似 ChatGPT 的体验。

Open WebUI（需要 Docker）

  1. 安装 Docker Desktop（下载）
  2. 运行命令： 
    docker run -d -p 3000:8080 --add-host=host.docker.internal:host-gateway -v open-webui:/app/backend/data --name open-webui --restart always ghcr.io/open-webui/open-webui:main
  3. 访问 http://localhost:3000，注册本地账号即可使用。

Chatbox（桌面客户端，无需 Docker）

下载地址：https://chatboxai.app/zh，支持连接 Ollama。

4. 自定义模型和系统提示

基于现有模型创建一个专属助手，例如英语老师、文案助手等，使用 Modelfile。

示例

  1. 创建 Modelfile 文件： 
    FROM deepseek-r1:7b
SYSTEM 你是一个专业的英语老师，请用简单易懂的方式解释英语语法。
PARAMETER temperature 0.7
  2. 创建自定义模型： 
    ollama create my-english-teacher -f Modelfile
  3. 运行： 
    ollama run my-english-teacher

还可以通过 ollama show 查看模型详情。

5. 编程助手（VS Code + Continue）

将 Ollama 接入 VS Code 的 Continue 插件，实现完全离线的编程辅助。

步骤

  1. 安装 VS Code 插件 Continue。
  2. 打开 Continue 设置，添加 Ollama：
    • Provider: Ollama
    • Model: deepseek-r1:7b（或 codellama）
    • Base URL: http://localhost:11434
  3. 在 VS Code 中按 Ctrl+L（或 Cmd+L）打开 AI 对话。

6. 搭建本地知识库问答

结合 AnythingLLM 或 PrivateGPT，让 AI 根据本地文档回答问题（RAG）。

使用 AnythingLLM

  1. 下载安装 AnythingLLM。
  2. 在设置中选择 Ollama 作为 LLM 提供商，并选择模型。
  3. 创建工作区，上传文档（PDF、Word 等）。
  4. 开始提问，AI 会根据文档内容回答。

原理：文档被分割成小块，用嵌入模型转换成向量，提问时检索最相关片段，再让大模型生成回答。

7. 多模态模型：图片识别

Ollama 支持多模态模型，可以输入图片并让模型描述内容。

示例：使用 Llava 模型

ollama run llava

然后输入：

请描述这张图片：/path/to/image.png

模型会分析图片并给出回答。应用场景：图片内容识别、OCR、辅助视觉问答。

8. 嵌入模型：文本向量化

嵌入模型将文本转换为数字向量，用于语义搜索、文本分类、相似度计算等。Ollama 提供 nomic-embed-text 等嵌入模型。

示例

ollama pull nomic-embed-text
curl http://localhost:11434/api/embeddings -d '{
  "model": "nomic-embed-text",
  "prompt": "你好，世界"
}'

返回一段数字向量，代表语义。可用于本地文档检索、推荐系统、聚类分析等。

9. 常用管理和优化技巧

  • 查看已安装模型：ollama list
  • 查看正在运行的模型：ollama ps
  • 停止某个模型：ollama stop deepseek-r1:7b
  • 删除模型：ollama rm deepseek-r1:7b
  • 修改模型存储位置：设置环境变量 OLLAMA_MODELS，例如 D:\ollama_models。
  • 调整并发数：环境变量 OLLAMA_NUM_PARALLEL。
  • GPU 加速：有 NVIDIA 显卡时自动使用 CUDA，AMD 显卡在 Linux 下支持 ROCm。

10. 注意事项

  • 硬件要求：模型越大，需要的内存和显存越多。7B 模型至少 8GB 内存，13B 需要 16GB，70B 需要 48GB+。
  • 存储空间：模型文件较大（几个 GB 到几十 GB），注意磁盘空间。
  • 隐私：所有数据都在本地，不会上传到云端（除非主动配置远程服务）。
  • 速度：本地推理速度取决于硬件，普通 CPU 上 7B 模型可能每秒几个字，GPU 会快很多。

总结

Ollama 是一个功能丰富的本地 AI 平台，除了运行 DeepSeek，还能：

  • 运行各种开源大模型
  • 搭建本地 API 服务
  • 使用图形化聊天界面
  • 创建自定义 AI 助手
  • 作为编程助手
  • 搭建私有知识库
  • 进行图片识别
  • 做文本嵌入和检索

建议从运行一个 7B 模型开始，然后尝试 Open WebUI 或 Chatbox 获得更好的体验。Ollama 让本地大模型的使用变得简单而强大。
